# fixtures/news

The news pack (ADR-027): what the news pollers (`workers/poll-news`) have seen, committed like the ship pack because it is the site's data until Fly and Postgres exist.

- `ContentItem.json`: every content item published on or after the news window, 14 May 2026, the first day of DefenseCon 2956 (ADR-031: `NEWS_WINDOW_START` in `packages/schema`; the pollers record nothing older and the site shows nothing older), every revision, append-only from there (CLAUDE.md section 5). A source that changes an item makes a new row with the next revision; the site shows the latest revision of each and hides rows with the takedown flag. Ids are derived from the source, the source's own id and the revision, so a row is the same row everywhere.
- `roadmap-state.json`: RSI's Release View board as the poller last saw it; the next run's changes against it become roadmap items.
- `Author.json`: every CIG staff member seen on Spectrum, with handle, display name, role, first seen and post count, nothing else. The site reads it only with `SPECTRUM_MODE` on.
- `samples/`: one real response per source from 2026-11-10 (RSI's Comm-Link hub page, the wiki's record of one Comm-Link, a cut of the roadmap board) and the two YouTube channels' feeds from 2026-11-11 (ADR-050), which the parsers' unit tests read. No test reaches the network.

Videos are content items of source `video` (ADR-050): CIG's uploads on the Star Citizen and Squadron 42 YouTube channels, each with its own id, its page on YouTube, its title, the first paragraph of its description as the summary, the description as escaped paragraphs, and the channel's name in `forum`. The feeds list each channel's fifteen newest; the pack keeps every one it has seen.

Comm-Link text comes from the Star Citizen Wiki API's record of each Comm-Link (the hub page carries titles and links, the transmission pages no text), and the feed credits it (`WIKI_CREDIT`). Every item links its original on the source site.

Run the pollers by hand with `pnpm workers:poll-news` (`--source comm_link`, `roadmap` or `video` for one). `.github/workflows/news.yml` runs them every thirty minutes (one YouTube feed an hour, the two channels in turn, from the :07 schedule only; CLAUDE.md section 9) and commits what changed; a run with an error writes nothing. `pnpm workers:poll-spectrum` writes Spectrum items and authors when `SPECTRUM_MODE` is `poll` (the newest page of the last week's staff posts; `--backfill <pages>` reads that many pages of the last year, five minutes apart, and the store keeps only what the window admits) or `feed`; the real responses its tests read are in `fixtures/spectrum/samples/`. After the search, the worker reads each new post's thread in full from Spectrum's thread endpoint (ADR-037), five minutes apart, and writes a new revision of the post's `body_html` with its own blocks and pictures (`--threads <n>` reads up to that many threads due, for a backfill); `fixtures/spectrum/thread-state.json` says which threads it has read. Spectrum items in the pack reach a page only when the site's own `SPECTRUM_MODE` is on.
