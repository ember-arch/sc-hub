# workers

Long-lived processes on Fly.io: the news pollers and Spectrum adapter (spec 03), the import job that reads the R2 manifest and flips the channel pointer (spec 01), and the link-entities job (spec 03). One workspace package per worker. `poll-news` (ADR-027) is the first: the Comm-Link and roadmap pollers, writing the news pack in `fixtures/news/` and run from `.github/workflows/news.yml` every thirty minutes until Fly. `poll-spectrum` is the Spectrum adapter of spec 03 (`feed` and `poll`; a developer post is one highlighted with the staff role, or by a badged or listed member), writing the same pack and `fixtures/news/Author.json`; it runs only with `SPECTRUM_MODE` set to `poll` (no credential; Spectrum's search answers without a sign-in) or `feed` (with `SPECTRUM_FEED_URL`), and the site shows its items only when its own `SPECTRUM_MODE` is on.
